## Stack Overview

The MERN stack provides a complete JavaScript solution for building dynamic web applications:

| Component | Technology | Role in Project |
|-----------|-----------|-----------------|
| **M** | MongoDB | Database for products, users, orders |
| **E** | Express.js | REST API server, route handling, middleware |
| **R** | React | Frontend UI, component-based interface, state management |
| **N** | Node.js | Server runtime, package management |

## Prerequisites

- **Node.js** (v16 or higher) and **npm** installed
- **MongoDB** installed locally or a MongoDB Atlas account
- Basic understanding of JavaScript, React, and REST APIs
- A code editor such as VS Code

---

## Getting Started (once implemented)

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd MERN
   ```

2. Set up the E-Commerce project:
   ```bash
   cd e-commerce

   # Install backend dependencies
   npm install

   # Install frontend dependencies (if separate client folder exists)
   cd client
   npm install

   # Start the development servers
   npm run dev
   ```

3. Configure environment variables for MongoDB connection, JWT secrets, and other settings as needed.
